# Plausibil redesigned dashboard

The frontend has been redesigned around the provided reference dashboard while keeping Plausibil's evidence-first framing.

Highlights:
- Top navigation with Overview, Companies, Reports, Investigation, and Data Explorer
- KPI cards for reports, companies, review flags, and boundary changes
- Emissions trend chart with actual/baseline series
- High-priority review flag queue
- Metric normalization and validation quality panel
- Sector comparison chart
- Recent processing events
- Investigation workspace with source evidence and provenance chain
- Existing FastAPI/SQLite backend remains unchanged

Run with the existing SQLite setup instructions in `SQLITE_SETUP.md`.
